## Project Overview

Riyadh Train Integrated System is a web-based platform designed to simplify the Riyadh Metro ticket booking experience.

The website allows users to create accounts, log in, explore ticket options, and navigate the booking process.

## Key Features

- User registration and login
- Authentication using Firebase
- Ticket selection based on different durations
- Booking and payment interface
- Interactive website navigation
- User-friendly interface design
