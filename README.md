## Project Overview

Riyadh Train Integrated System is a web-based platform designed to simplify the Riyadh Metro ticket booking experience.

The website provides an interface for users to create accounts, log in, explore ticket options, and navigate the booking process.

## Key Features

- User registration and login
- User authentication using Firebase
- Ticket selection based on different durations
- Booking and payment interface
- Interactive navigation between website pages
- User-friendly interface design

## Technologies Used

- **HTML** – Website structure
- **CSS** – Styling and interface design
- **JavaScript** – Interactive functionality
- **Firebase Authentication** – User authentication
